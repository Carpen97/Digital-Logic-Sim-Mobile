✨ **New Features**
• **RGB LED Chip** – New display component with true colour! Three 8-bit inputs (R, G, B), on-chip light updates in real time. Find it under DISPLAY in the chip library 🎨
• **Labels on buttons** – Add labels to button chips and position them (e.g. bottom, centre, top)
• **Label chip** – New component for annotations and circuit notes! Place from BASIC collection, right-click to Edit text and background colour. No pins, just display text that persists with your project 📝
• **Speaker V2 (Experimental)** – High-resolution audio output chip in the chip library. Experimental; feedback welcome 🔊

🔧 **Improvements & Fixes**
• **Level cheating fix** – Solutions with disallowed components (e.g. ROM) inside custom chips are now rejected; leaderboard scores are fair (for now. until the next exploit. 😉)
• **Simulation speed not saving** – Custom “Steps per clock tick” and “Steps per second” settings no longer reset to 250/1000 when you confirm preferences with the Simulation section collapsed
• **Level Upload / Project Sharing auth** – Fixed stale “Signed in as X” after logout; logout clears cache. Users without a username get a proper Claim Username flow
• **Customization view pin layout** – Pin positioning fixed for Rectangle (Custom layout) and non-rectangle shapes (Default layout)
• **About menu Discord logo** – Discord icon no longer shows as a white rectangle
• **Wire edit segment deletion** – Restored deleting wire segments (remove vertices) in wire edit mode
• **Delete-mode ghost hitbox** – Fixed the top area staying non-interactive after closing the delete popup
• **Unity security update (Android)** – Builds now use the latest patched Unity Editor for Google Play compliance and security
