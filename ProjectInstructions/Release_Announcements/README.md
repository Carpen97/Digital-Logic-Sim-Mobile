# Release Announcements

This folder holds **Discord (and other) release announcements** for Digital Logic Sim Mobile.

- **Purpose:** Draft and store the exact text used when announcing a new version (e.g. in Discord).
- **Naming:** `Release_2.1.6.XX_Discord.md` (or similar) so it’s clear which release and channel.
- **Workflow:** When a release is done, create or update the announcement here, then copy-paste into Discord (and adjust links/placeholders as needed).
